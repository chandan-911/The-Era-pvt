## ✨ Features & Technical Highlights

- **Luxury Aesthetics & Responsive Design**:
  - Clean, minimalist aesthetic with glassmorphism sticky header (`backdrop-filter`).
  - Fluid typography scaling using CSS `clamp()`.
  - Fully responsive across desktop, tablet, and mobile with a custom interactive navigation drawer.
- **Generative Engine Optimization (GEO) & Advanced SEO**:
  - Embedded **JSON-LD Structured Data** (`HomeAndConstructionBusiness`, `WebSite`, `FAQPage`) for search engines and AI engines.
  - Custom [`llms.txt`](file:///d:/BZNS/The%20Era%20Pvt/llms.txt) configuration delivering contextual brand clarity to AI crawlers.
  - Complete Open Graph and Twitter card meta tags for rich social sharing.
  - Optimized [`robots.txt`](file:///d:/BZNS/The%20Era%20Pvt/robots.txt) welcoming search crawlers and AI bots (GPTBot, ClaudeBot, PerplexityBot, etc.).
  - XML Sitemap ([`sitemap.xml`](file:///d:/BZNS/The%20Era%20Pvt/sitemap.xml)) integration.
- **Interactive UI Components**:
  - Native HTML `<details>` and `<summary>` accordion for FAQs with CSS rotation animations.
  - Smooth scroll navigation and one-click direct WhatsApp integration (`wa.me`).

## 🚀 Getting Started

### Local Development
Since this is a lightweight, zero-dependency static site, no build steps or package managers are required.

#### Option 1: Live Server (VS Code Extension)
Right-click [`index.html`](file:///d:/BZNS/The%20Era%20Pvt/index.html) and select **Open with Live Server**.

#### Option 2: Python HTTP Server
Run the following command in your terminal within the project folder:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000` in your web browser.

#### Option 3: Node `npx serve`
```bash
npx serve .
```
